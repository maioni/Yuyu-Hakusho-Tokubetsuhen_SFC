# Reference art (text-free plates)
Clean, text-free versions of the game's label plates, supplied by the project owner (AI-redrawn from the JP screens).
Used as source art by `tools/plates/` (modes, menus): the plates are rebuilt from these and the labels are drawn with the pixel font.
- `quadrados_limpos_alta_resolucao.zip` - 13 squares: stages 01-04, modes 05-08, config 09-11, menus 12-13.
- `quadrados_menu_limpos_2x.zip` - 5 menu squares at 2x: 14 Free Battle, 15 Options, 16 Difficulty, 17 Sound, 18 Buttons.
(The "OPTION / KEY-CONF / RANK / SOUND" lettering in the Options square belongs to the background art on purpose.)
- `27_tela_ordem_equipe_sem_texto_4x.png` - full team-order screen ("choose the fighting order") without any text, 4x (1024x896). Source for the Cancel portrait body (`tools/plates/order.py`, copy in `tools/plates/ref/27_ordem_equipe_sem_texto.png`).
- Also stored in `tools/plates/ref/`: 14-26 (menu and mode/stage squares), jp_*.png (Japanese screenshots), menu_tilemaps.json, menu_pal.json.
